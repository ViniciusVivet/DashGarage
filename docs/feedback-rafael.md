# Feedback de validacao do CRM

Responsavel: Rafael

## Objetivo

Testar se o CRM parece util para uma concessionaria real.

Nao basta dizer "esta bom". O feedback precisa apontar ajustes praticos:

- algo que falta para o vendedor trabalhar melhor;
- algo que o gerente precisaria ver;
- algo que esta confuso;
- algo que nao faz sentido no fluxo comercial.

## Checklist

- [ ] Cadastrei 5 vendedores ficticios.
- [ ] Cadastrei 50 leads ficticios.
- [ ] Cadastrei 20 veiculos ficticios.
- [ ] Cadastrei 20 propostas.
- [ ] Cadastrei 10 vendas.

## Perguntas

1. O fluxo ficou parecido com uma concessionaria real?
2. Que campo esta faltando?
3. Que campo esta sobrando?
4. Qual status nao faz sentido?
5. O que melhoraria para o vendedor usar de verdade?

## Modelo de feedback

### Problema encontrado

Exemplo: nao existe campo para registrar se o cliente precisa de financiamento.

### Por que isso importa

Exemplo: em concessionarias, financiamento muda a chance de fechar venda e afeta o prazo da negociacao.

### Sugestao

Adicionar campo `precisa_financiamento` ou melhorar `forma_pagamento` com opcoes padronizadas.

### Prioridade

Alta, media ou baixa.
