# Relatorio executivo

Responsavel: Rafael

## Objetivo

Consolidar os aprendizados do projeto como se fosse uma entrega para o dono ou gerente de uma concessionaria.

## Estrutura sugerida

### 1. Contexto

Explique o problema:

- leads espalhados;
- pouca visibilidade do funil;
- dificuldade para medir vendedores;
- estoque parado;
- margem pouco acompanhada.

### 2. Base analisada

Descreva os dados usados:

- quantidade de leads;
- quantidade de vendedores;
- quantidade de veiculos;
- quantidade de propostas;
- quantidade de vendas;
- periodo simulado.

### 3. Principais indicadores

Listar:

- total de leads;
- total de vendas;
- faturamento;
- ticket medio;
- margem total;
- taxa de conversao;
- veiculos disponiveis.

### 4. Insights

Exemplos:

- origem com mais leads;
- origem com melhor conversao;
- vendedor com melhor desempenho;
- veiculos mais parados;
- propostas que nao viraram venda;
- motivos de perda mais frequentes.

### 5. Recomendacoes

Exemplos:

- investir mais na origem que converte melhor;
- revisar anuncios de veiculos parados;
- padronizar motivo de perda;
- criar rotina de follow-up;
- acompanhar margem alem de faturamento.

### 6. Limitacoes

Explicar o que ainda limita a analise:

- dados ficticios;
- pouco historico;
- falta de CRUD completo;
- campos que podem mudar apos validacao real.

### 7. Proximos passos

Sugerir melhorias:

- formularios completos no CRM;
- exportacao CSV;
- dashboard Power BI;
- automacao de follow-up;
- metas por vendedor.
