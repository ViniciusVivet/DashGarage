# Dicionario de dados

Base inicial definida em `database/schema.sql`.

## Tabelas

- `vendedores`: equipe comercial, metas e comissao.
- `leads`: oportunidades comerciais e origem do funil.
- `veiculos`: estoque disponivel, reservado ou vendido.
- `propostas`: ofertas enviadas para leads.
- `vendas`: vendas fechadas, faturamento, margem e comissao.
- `atividades`: historico de contato com leads.
