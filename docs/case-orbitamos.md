# Case Orbitamos

## Problema

Concessionarias pequenas e medias perdem visibilidade sobre funil comercial,
origem dos leads, estoque parado, margem e performance de vendedores.

## Solucao

DashGarage centraliza o registro operacional em um CRM web e gera base para uma
esteira analitica com Supabase, SQL, Excel, Power BI e Python.

## Stack

Next.js, TypeScript, Tailwind CSS, Supabase, PostgreSQL, Vercel e GitHub.
